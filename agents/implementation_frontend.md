# Implementation: frontend

## File structure

```
frontend/index.html : SPA shell
frontend/package.json : frontend scripts and dependencies
frontend/src/App.tsx : backend health indicator and the "Ask AI" placeholder button
frontend/src/main.tsx : mounts React
frontend/tsconfig.json : typecheck settings
frontend/vite.config.ts : dev server :5173, proxies /api to :3000
```
