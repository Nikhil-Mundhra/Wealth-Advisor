## Key Behavioral Invariants Verified

1. **Zero ungrounded LLM arithmetic:** Advisory replies and rationales flow through `backend/src/modules/advisory/domain/calculation-shield.ts`, rejecting fabricated numbers and falling back to deterministic engine outputs.
2. **Fail-closed Tier 3 trade authorization:** `execute_sandbox_trade` in `backend/src/modules/advisory/domain/tool-registry.ts` and `/api/wealth/execute` in `backend/src/modules/wealth/wealth.api.ts` reject execution with HTTP `403` (`WL_1004`) unless a signed WebAuthn P-256 assertion passes verification against an active single-use challenge.
3. **Self-financing rebalance conservation:** Across randomized drift and weighting inputs, `BUY` legs never exceed proceeds generated by `SELL` legs (`backend/test/unit/rules/property-invariants.test.ts`).
4. **Admin provisioning & one-time key display:** Verified in `frontend/src/app/routes/admin-pages.test.tsx` (`4/4` tests passed), covering tenant creation with slug auto-derivation and API key issuance with one-time secret alert rendering.
