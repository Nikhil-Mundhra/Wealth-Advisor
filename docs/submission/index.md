# FinTechathon submission deliverables

Read this first when preparing, reviewing, or presenting the hackathon submission package. Each file below is grounded in implemented modules, architecture docs, and observed test evidence.

## File structure

```
docs/submission/demo-video-script.md : timed presenter script covering core user, advisor, passkey, and admin flows
docs/submission/execution-evidence.md : observed verification outputs across lint, property fuzzing, contract parity, SLA, unit, and build gates
docs/submission/presentation-deck.md : slide-by-slide architecture, compliance, and product pitch deck
docs/submission/security-self-assessment.md : security posture assessment covering PII shielding, passkey step-up, tenant isolation, and invariants
```
