# Design tokens

Source: `@theme` in `frontend/src/styles/globals.css`. Each token becomes Tailwind utilities by its suffix: `--color-ink` → `text-ink`, `bg-ink`; `--radius-field` → `rounded-field`; `--font-sans` → `font-sans`.

| Family | Tokens |
|---|---|
| font | `sans` (DM Sans) |
| color | `brand-50` `brand-100` `brand-600` `brand-700` `brand-900` `ink` `muted` `subtle` `line` `danger` |
| radius | `field` |
